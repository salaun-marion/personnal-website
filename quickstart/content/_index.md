austere

A minimal theme for Hugo with a focus on writing.

austere emphasises readability first. By default, a page makes no external requests - the stylesheet is inlined, the icons are inline SVG, and the typography uses common fonts a system should already have.

The design owes a lot to Zap by jimmyff. austere started out as a theme for Zola.
Features

    Internal CSS, no web fonts, nothing loaded from a CDN
    Light, dark, or follow the system
    Serif typography
    Responsive images straight from Markdown
    Syntax highlighting that follows the colour scheme
    RSS, including per-tag feeds
